# UI 设计规范（定稿 v1.0）

> 本文档定义产品的视觉语言。所有前端开发/视觉改动必须先读本文档。
> 设计原则冲突时，本文档 > 组件库默认样式 > 个人偏好。

## 1. 设计定位

把"车间工具"做出"专业桌面应用"的质感——对标 Fusion 360、Linear、Raycast 这类现代工具的观感，**明确区别于**传统 CAM/工业软件的灰色挤压式界面。

一句话：**克制、留白、清晰，切割图是主角。**

## 2. 设计语言（已与用户确认）

| 维度 | 决策 |
|---|---|
| 主色调 | **中性灰体系**（黑白灰为主，克制的现代工具风） |
| 强调色 | **单一强调色**，只用于关键操作（"计算"按钮、激活态、主 CTA）——见 §3 |
| 主题模式 | **浅色为主，可切换深色**（默认浅色，客户现场/打印友好；深色为可选） |

**禁止**：拟物金属质感、高饱和渐变、多色混搭、花哨装饰。

## 3. 色彩系统

### 3.1 中性灰阶（两套主题共用骨架）

| Token | 浅色值 | 深色值 | 用途 |
|---|---|---|---|
| `bg` | `#F7F7F8` | `#0F1115` | 页面背景 |
| `surface` | `#FFFFFF` | `#161A20` | 卡片/面板 |
| `border` | `#E4E4E7` | `#2A2F38` | 分割线/描边 |
| `text-primary` | `#18181B` | `#F4F4F5` | 主文字 |
| `text-secondary` | `#52525B` | `#A1A1AA` | 次要文字/标注 |
| `text-disabled` | `#A1A1AA` | `#52525B` | 禁用态 |

### 3.2 强调色（单一）

| Token | 浅色值 | 深色值 | 用途 |
|---|---|---|---|
| `accent` | `#E8590C` | `#F76707` | **仅限**：主操作按钮（计算/导出/识别）、选中态、激活态、焦点环 |

- 强调色为**暖橙**（呼应木材质感的现代演绎，在灰底上出挑）
- 使用纪律：**一个页面强调色出现的面积 ≤ 5%**，其余全部走中性灰。违反此条 = 设计倒退。

### 3.3 语义色

| Token | 值 | 用途 |
|---|---|---|
| `success` | `#2F9E44` | 通过、导入成功、额度充足 |
| `warning` | `#F59F00` | 警告/需要人工确认（AI 识别格子）。与 accent 同属暖色系但色相明显区分（黄 vs 橙），避免与选中态混淆 |
| `danger` | `#E03131` | 错误、删除、额度不足 |
| `info` | `#1971C2` | 信息提示、进行中 |

> **双通道编码（不只靠颜色）**：审查表中"AI 待确认格子"在 warning 浅底之外，**必须叠加斜纹或角标标记**——颜色之外的第二通道，确保与"选中态（accent 描边）"同时出现时可区分，且色弱用户可辨（WCAG 无障碍要求）。

### 3.4 零件色板（切割图专用，独立于 UI 主题）

- 一组**奶油淡彩、高区分度**的 12 色板（S 18~26%、L 79~91%，以用户参考色 `#EEE4E3` ≈ hsl(5°,24%,91%) 为调性基准）：相邻色相设计间隔 ≥27°（hex 量化后 ≥24°）+ 明度梯度（暖亮冷暗）双通道区分；红粉/品红/紫/蓝/绿/黄绿/橄榄/驼棕，与灰色余料底色可区分（弃用低饱和青灰调）；深字在其上对比充足
- 自动分配：零件按 id 哈希取色，**同类零件（同 id）永远同色**；仅异类相邻零件撞色时顺移一位避撞，黑色描边负责区分相邻同类
- 余料/废料区：半透明浅灰 `rgba(127,127,127,0.15)`，永不抢零件视觉
- **禁止白色/近白色**——零件填充必须与板材底色（浅色主题 `#FFFFFF`）可区分（淡彩 + 黑描边双重保证）
- 色板定义在 `src/domain/palette.ts`（纯数据），**网页切割图与 PDF 导出共用**，两处渲染效果一致

## 4. 字体

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| Display | 20px / 600 | 页面标题、方案统计大数字 |
| Title | 15px / 600 | 卡片标题、面板标题 |
| Body | 13px / 400 | 正文、表格 |
| Caption | 12px / 400 | 标注、状态、提示 |

- 字体族：系统无衬线栈（`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`），不引外部字体（桌面端离线优先，禁 CDN 字体）
- 数字建议 `tabular-nums`（等宽数字，表格/统计对齐）

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：logo / 项目名(可编辑) / [▶计算] / 导出▾ / 语言 / 账号   │
├──────────┬──────────────────────────┬────────────────────┤
│ 左栏      │ 中央（视觉主角）           │ 右栏                │
│ 输入区    │ 切割图可视化区             │ 结果统计            │
│ (零件/板材/│ （板材卡片流/单板大图）     │ (方案总览+单板翻页,   │
│ 识别/历史) │                          │  仅计算后出现)       │
├──────────┴──────────────────────────┴────────────────────┤

└──────────────────────────────────────────────────────────┘

- 左栏固定宽 320px，右栏固定宽 300px，中央自适应——大屏优先，Web 端窄屏可折叠侧栏

- 留白：卡片间距 16px，卡片内边距 20px，绝不密集堆砌

### 6.2 项目工作台（核心，三栏骨架 v1.2 · 方向 D 定稿）

> **编辑与结果同屏**（v1.2 修订，取代 v1.1 编辑/结果互斥状态机）：
> 左栏 560px = 常驻编辑区（零件清单置顶 + 板材库 + 工艺参数）；
> 中央 = 结果常驻（无结果引导卡 / 板材卡片流 / 单板大图模态）；
> 右栏 300px = 统计 + 历史。取消「编辑态/结果态」切换，改完零件点计算立即看影响。

┌──────────────────────────────────────────────────────────────────┐

├───────────┬───────────────────────────────┬─────────────────────┤
│ 左栏 560px │ 中央（结果常驻，主角）          │ 右栏 300px           │
│ (编辑区常驻)│                               │ 方案总览(卡片)        │

│  (标题+⋯菜单│  [有结果] 板材卡片流            │ 零件详情(选中时)      │
│   +网格表格,│  [点卡片] 单板大图（模态全屏）   │ 历史方案(折叠)        │
│   滚动)    │  dirty 时顶部提示条「有改动未计算」│                     │
│ ▸ 板材库    │                               │                     │
│  (网格表格)│                               │                     │
│ ▸ 工艺参数  │                               │                     │
│  (表单)   │                               │                     │
├───────────┴───────────────────────────────┴─────────────────────┤
│ 底部状态栏: 计算进度 | 板数 | 利用率 | 网络状态                       │
└──────────────────────────────────────────────────────────────────┘
```

**要点**：
- **左栏 = 常驻编辑区（560px，全屏高）**，从上到下：零件清单（标题行 + ⋯ 菜单 + 网格表格，占大部分高度，独立滚动）/ 板材库（网格表格，固定）/ 工艺参数（表单，固定）。编辑与结果同屏，无状态切换。
- **Excel 式网格表格**（零件表与板材库统一形态）：antd Table `bordered` + `sticky`（表头灰底冻结）+ `size="small"` + CSS 行高压缩（td padding 2px 8px，行高 ~26px，全屏高下零件表可见 ~20 行）；**行号列**（灰底、`#` 序号）；数字列**右对齐 tabular-nums**；单元格即输入框（borderless，点击即编辑、失焦保存）；**选中单元格 = 强调色描边 + 浅橙底**；行悬停浅灰底；旋转列表头全选勾选（混合态半选）。
- **零件清单标题行**：「零件清单」标题 + 计数 + 右上角 **⋯ 菜单**（添加零件 / 批量粘贴 / AI 识别 / 导入 CSV / 导出 CSV）——工具行操作全部收进菜单，不占表格高度。
- **零件表列宽**（左栏 560 内可用 ≈536）：行号 24 / 名称 112 / 长 56 / 宽 56 / 数量 44 / 旋转 40 / 板材 72 / 封边 60 / 删除 32 ≈ 496px，无横向滚动。
- **板材库**：勾选 | 名称 | 尺寸 | 单价 | 编辑 五列网格表格（行高 24px），勾选行即启用（≥1 行强制），「+ 添加规格」追加行；**价格功能关闭时不显示单价列值**。
- **工艺参数**：普通表单（**不表格化**）——标签 + 输入框/选择框双列紧凑布局（切缝 / 修边 / 计算质量 / 最小余料）；⚙ 设置入口（价格核算弹窗，全局配置）。
- **中央 = 结果区（常驻）**：无结果 → 引导卡；有结果 → 板材卡片流（stagger 淡入）；点击卡片 → 单板大图模态（全屏，ESC 关闭）；数据改动未重算（dirty）→ 顶部警告条「有改动未计算」。
- **右栏 = 统计 + 历史（常驻）**：方案总览 + 单板统计（◀▶ 翻页）+ 零件详情 + 历史方案（折叠，从原左栏移入）。
- **历史方案模式**：左栏零件清单显示历史快照（只读网格，无 ⋯ 菜单，标题旁「历史方案」标记）；顶栏出现「继续编辑」（快照零件导入当前项目）。
- **计算按钮顶栏常驻**：数据改动后按钮变橙（dirty 提示"有改动未计算"），计算中变"停止"。
- **导出入口顶栏**（PDF/DXF 下拉）；零件/配置改动未重算（dirty）时导出禁用——防止旧方案与新清单不符。

## 7. 切割图可视化（视觉主角，最高优先级）

- 每张板 = 一张卡片：左上角"第 N 张 / 2440×1220 / 利用率 %"，主体为 SVG 切割图
- 切割图：零件矩形填充低饱和零件色（**细微垂直渐变：上亮下暗 ±4.5%**，克制不抢文字；PDF 保持纯色），圆角 2px，**黑色描边 1.2px**（`non-scaling-stroke`，缩放/卡片缩放下恒为 1.2 屏幕像素；黑色描边负责区分相邻同类零件）；余料区半透明浅灰
- 零件标注：面积 > 40,000 mm² 深色字**一行 = 零件名称**（字号自适应加大，淡彩填充上深字凸显，白 halo 保证清晰）；尺寸信息由内侧尺寸标注提供，中心不再重复
- **内侧尺寸标注（所有零件）**：长边内侧标长度（顶部居中）、短边内侧标宽度（左侧竖直旋转 -90°），**数字恒在零件内部、距边 4mm**（长短边同字号、位置对称），永不与相邻零件/余料干扰；白 halo 深灰字，**字号自适应上限 26**（按数字字符数与零件宽/高约束，大零件字大、窄条自动缩）；**极小零件（两数字放不下）只标长度、省略宽度**
- 文字可读性：**深色标注字统一带白色描边 halo**（SVG `paint-order: stroke`；PDF 以白色偏移阴影模拟）——淡彩填充上深字对比充足，禁止无 halo 的文字
- 交互：
  - 悬停零件 → 高亮（亮度提升） + 表格对应行联动高亮
  - 点击零件 → 选中态（强调色描边），右栏显示该零件详情
  - 单板模式：点击卡片放大为单板大图，可缩放/平移
- 精密切割线（如需要）：1px 虚线 `#868E96`，不抢零件视觉

## 8. 微动效（克制原则）

| 场景 | 动效 |
|---|---|
| 计算进行中 | 顶栏/按钮内环形进度 + 底部状态栏百分比 |
| 结果出现 | 板材卡片逐个淡入 + 轻微上移（stagger 80ms） |
| 悬停/选中 | 150ms ease 过渡（颜色/描边/阴影） |
| 页面/面板切换 | 200ms 淡入淡出，**禁止**滑动切换 |
| 深/浅主题切换 | 300ms 全局过渡 |

- 全部动效 150~300ms 之间，`prefers-reduced-motion` 时全部禁用
- 动效是"反馈"，不是"表演"——不做任何装饰性循环动画

## 10. 反模式清单（出现即返工）

- ❌ 灰色挤压式全屏表格（无留白、无层次）
- ❌ 全屏表单页（配置应放左栏折叠面板，而不是独占页面）
- ❌ 强调色大面积铺开（按钮全彩、多色混搭）
- ❌ 拟物金属/木质纹理装饰
- ❌ 高饱和渐变背景
- ❌ 装饰性循环动画
- ❌ 小字号（<12px）+ 低对比度文字（对比度 < 4.5:1）

## 11. 实现约定

- Ant Design 为主题基线：通过 token 定制覆盖（`theme.token` 映射 §3 色彩），不写散落的魔法颜色
- 所有颜色走 token / 设计变量，**禁止**组件里硬编码色值
- 深色主题 = 同一套 token 换深色值（CSS 变量或 antd dark algorithm），组件代码零分支
- 新页面组件先按 §5 布局骨架落位，再谈细节
